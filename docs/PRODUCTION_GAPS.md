# Production gaps

This repository intentionally stops at synthetic R&D. The following remain blocked behind named human owners, externally reviewed protocols, operational evidence, and commit-bound approvals:

- real identity, device authorization, adult assurance, revocation, and appeals;
- signed replay-resistant interests and bilateral match/phase receipts;
- reviewed E2EE messaging, delivery, ordering, retry, offline mailbox, push privacy, and multi-device semantics;
- encrypted local custody, backup, migration, deletion, export, recovery, and key-loss behavior;
- cross-service block/unmatch/account-deletion propagation;
- BLE proximity, permission/background/battery behavior, and replay/relay/stalking defense;
- E2EE location payloads, receiver purge, stale-cache behavior, and coercion review;
- reports, evidence consent, moderation staffing, appeals, child-safety, NCII, support, and emergency operations;
- hostile media processing, billing, entitlements, creator moderation, refunds, taxes, payouts, and fraud controls;
- accessibility, fairness, privacy/DPIA, legal, jurisdiction, app-store, infrastructure, incident-response, and external security review.

No passing local test closes any of these gates.
