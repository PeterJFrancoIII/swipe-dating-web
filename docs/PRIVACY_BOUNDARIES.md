# Privacy boundaries

## Allowed in the unencrypted local R&D file

- display name (64 characters);
- about text (500 characters);
- optional pronouns (40 characters);
- gender identities from the living catalog (`he`/`she`/`other` and older labels map onto it);
- self-declared interest, hobby, personality, and bedroom tags (top 5 each);
- card-visibility flags for optional profile fields (gender is always shown; sexual preference / Show me is never stored here and never shown);
- up to 50 synthetic cosmetic identifiers and the selected owned cosmetic;
- haptic-feedback preference;
- last non-sensitive tab (`Swipe` only; Matches is never persisted).

## Session-only

Birth date and adult-gate result; browser-session lookup; credentials; intent; gender-feed
settings; boundaries; fixed ranking evaluation; questionnaire answers; decisions; likes;
reciprocal fixtures; matches; messages; transcripts; blocks; bot reports; community votes;
reviewer reputation; risk assessments; moderation cases and synthetic adjudications; proximity;
encounters; location grants; identifiers; keys; secrets; payments; payouts; and the Matches
screen.

Deepen Connection / relationship-phase state is deleted from the product and must not return.

This R&D file is unencrypted and is not suitable for real users. A real-user build requires an
externally reviewed encrypted vault, key custody, backup/recovery, transfer, deletion/export,
corruption, reinstall, and key-loss behavior.
